# Промпт для внешней перепроверки кошачьих доз (без доступа к локальным JSON)

У тебя уже есть `HANDOFF_CATS_RECHECK.md` (общие правила и карта батчей).
Дополнительно приложены файлы:

1. `EXTERNAL_CATS_01_STATE_1.md` … `_4.md` — текущее состояние всех 797 пар
   «Кошки × препарат» из `drugs_calc.json`, `verified_dosages.json` и
   `drugs_registry.json` (по 200 строк в файле).
2. `EXTERNAL_CATS_02_PROTOCOLS_01_27.md`, `_28_54.md`, `_55_81.md` — полные протоколы
   81 батча: что было в базе, цитаты из инструкций, вердикты и URL-источники.
3. `EXTERNAL_CATS_03_FIX_LOGS.md` — все логи правок: что именно и на что менялось.

Локальные JSON у тебя нет и не нужно: работай только по этим текстам и по
открытым источникам (сайты производителей, vidal.ru, vetsnab.info, гос реестр).
Google/Yandex/DDG часто блокируют — ходи по прямым URL из протоколов.

## Что сделать

Перепроверь **все 797 пар** независимо: сверь текущее значение кошачьей ветви
и `fixed_dose['Кошки']` с текстом официальной инструкции по URL из протокола
(или найди лучший источник: реестр/производитель важнее справочника).

Создай один файл `CATS_CHANGE_LIST.md` — итоговый список «как/что/где поменять».
Формат одной строки:

```
| id | Препарат | Где (JSON-путь) | Сейчас | Должно быть | Почему (цитата) | Источник | Вердикт |
```

`Где` — например `drugs_calc.json → animal_specific["Кошки"].dose_per_kg`
или `verified_dosages.json → fixed_dose["Кошки"]`, либо «не менять».
`Вердикт` — один из: `ИСПРАВИТЬ`, `ПОДТВЕРЖДЕНО (без правки)`,
`ПРОТИВОРЕЧИЕ ВИДА (не трогать)`, `НЕТ ТЕКСТА ДОЗЫ (открытый вопрос)`.

## Правила (важнее всего)

- Правки только доз и единиц в кошачьей ветви и `fixed_dose['Кошки']`.
  `animals`, `calculator_applicable`, предупреждения, `species-safety` и
  `drugs_registry.json` — не трогать, только отмечать расхождения.
- Нет текстового подтверждения — дозу не выдумывать; писать «по инструкции»
  и открытый вопрос. При конфликте источников правда старшей организации.
- Наружные/глазные/ушные/спреи/капли/ошейники и вакцины/иммуномодуляторы
  численно как мг/кг не рассчитывать; нужен осмысленный или честный `fixed_dose`.
  При противоречии вида для инъекционных/пероральных форм `fixed_dose` не добавлять.
- Одноимённые id должны получать одинаковую правку; для дубликатов укажи все id
  в отдельной колонке или через запятую в `id`.
- id 10 `Изофлуран Миралек` — тестовый инвариант: без `fixed_dose`, не трогать.
- Если считаешь, что прежняя правка была ошибочной — укажи `ИСПРАВИТЬ ОТКАТОМ`
  с прежним значением из `EXTERNAL_CATS_03_FIX_LOGS.md` и обязательно цитатой.

## Итог

В конце файла — сводка: сколько пар проверено, сколько реальных ошибок найдено,
сколько подтверждено без правки, сколько открытых вопросов. Если доступ к
интернету есть — приложи новые/лучшие URL. Если нет — явно пометь «проверка
по приложенным протоколам, без независимого источника».

Ничего не коммитить и не пушить.
