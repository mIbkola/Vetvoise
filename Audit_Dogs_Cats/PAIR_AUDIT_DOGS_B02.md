## Открытые вопросы

- id 14 «Бонхакан»: в доступном тексте Vidal нет дозы для собак; официальный PDF
  Россельхознадзора — сканированный образ без текстового слоя. До появления
  текстовой инструкции текущие 2 мг/кг не подтверждены и не изменены.
- id 8, 16: registry/calc содержат «Собаки», но официальные инструкции описывают
  только продуктивных животных; по принятому правилу противоречия вида числовые
  ветви остаются без правки, `fixed_dose` для инъекционных форм не добавляется.
- id 10: подтверждённая ингаляционная схема не записана в `fixed_dose`, потому что
  `test/task194_search_regressions_test.dart` требует, чтобы «Изофлуран Миралек»
  оставался записью без дозы и скрывался поиском. Это тестовый инвариант, а не
  отсутствие источника.

## Доаудитные расхождения (не увеличены)

- id 17/18: в `drugs_calc.json` путь записан ключом `route`, в
  `verified_dosages.json` — `method`; дозовый смысл одинаковый (`1 мл (1 доза)`,
  в/м или п/к). Батч эти записи не трогал, расхождение не выросло.
- id 9: в registry `animals` пуст, хотя Vidal допускает собак и кошек; registry
  не изменялся по условию аудита.
- id 8/16: расхождение `animals` registry/calc с объектом инструкции зафиксировано
  как противоречие вида без правки данных.
