Глобальные поля **не менялись**: у id 1395 концентрация 20 мг/мл относится к
составу таблетки, у id 1400 150 мг/мл — к суспензии, у id 1415 глобальные
`concentration = "5 МЕ, 10 МЕ"`, `concentration_me = 10` и дозы других видов
остаются без изменений. По правилу синхронизации по `name` кошачья ветвь
обновляется во всех записях с названием «Окситоцин» (id 323 и 1415); остальные
виды в обеих записях не трогаются.
id 1398, 1403, 1406, 1417, 1419 — противоречия вида: дозы не менялись.
id 1395, 1410, 1420 — дозы подтверждены и сохранены. Повторная сверка
источников предлагала также править глобальные `dose_per_kg`/`course_days`/
`calculator_applicable` (id 1395, 1400, 1420) — эти поля общие с другими
видами и находятся вне области точечных правок, поэтому не изменялись;
кошачьи ветви и `fixed_dose` уже несут корректные схемы.
