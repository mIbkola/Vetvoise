### Правила правок
- Изменять только дозы и единицы в ветви `animal_specific["<Вид>"]` и,
  где нужно, `fixed_dose["<Вид>"]`.
- `animals`, `calculator_applicable`, предупреждения, `species-safety`,
  глобальные поля — **не трогать** (исключения фиксировать в протоколе).
- `drugs_registry.json` — только сверка по `trade_name`, не изменять.
- Наружные/глазные/ушные/спреевые/капельные средства и ошейники численно не
  рассчитывать; сохранять/добавлять осмысленный `fixed_dose`. Вакцины и
  иммуномодуляторы — не мг/кг, а осмысленный/честный `fixed_dose`.
- Явное противоречие вида: для наружных/ушных/пчелиных/глазных/вакцинных форм
  можно добавить осмысленный или честный `fixed_dose`; для инъекционных и
  пероральных противоречий — **не добавлять**.
- При дубликате имени все одноимённые id в `drugs_calc.json` получают одну и ту
  же правку через `id_fixes`; в `verified_dosages.json` — только если вид есть
  в `animals`.
- Синхронизация данных только через `scripts/pair_fix_helper.py`:
  `run_batch(batch_label, report_name, species_fixes, sources,
  global_fixes=None, fixed_fixes=None, species='Кошки', id_fixes=None)`.
  `fixed_fixes` действует только на имена из `species_fixes`; для fixed-only
  правки нужна запись в `species_fixes` с пустыми полями. Пустой `run_batch`
  перезаписывает `verified` — для no-op батча писать только лог напрямую.
- Тестовые инварианты не трогать: id 10 `Изофлуран Миралек` должен остаться
  без `fixed_dose` и скрытым в поиске (`test/task194_search_regressions_test.dart`).
